# Meta Ads Dashboard · Japan

Standalone Japan dashboard split from `phoebeinthehouse/meta-ads-dashboard`.

## Data sources

- Google Sheets Apps Script Web App
- `JP meta raw`
- JP creative image list candidate tabs
- Monthly exchange-rate and selling-price candidate tabs

## Dashboard

- By Creator
- By Product
- By Creative
- Weekly Trend
- Weekly Trend by Creative

The dashboard reads only Japan data. The Amazon US dashboard remains in:
https://github.com/phoebeinthehouse/meta-ads-dashboard

## Deployment

Publish `main` / root through GitHub Pages.
